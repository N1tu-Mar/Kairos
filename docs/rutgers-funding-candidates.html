Three things to know before you trust a number on this page

UNKNOWN is a finding, not a gap. The scraper cannot write a field without a supporting sentence. When a pitch competition's page never mentions equity, the equity row says UNKNOWN — not “no equity” — even though “no equity” is almost certainly right. Almost certainly right is how a wrong fact ends up on a real application.

Two of these pages are showing last year's cycle. RBS says December 12, 2025 and NJIT says November 4, 2025. Those dates passed 255 and 293 days ago. Read the award figures beside them as last cycle's too.

There are no founder reviews anywhere in here, and that is not a verdict on any program. None of these eight pages publishes them. The scraper has no code path that writes that field — it comes from people you talk to, or it stays empty.

Why nothing came back

  • The page renders its content in the browser, so a static fetch returns a shell reading “This application requires JavaScript to be enabled.” The failure is recorded on the run rather than silently becoming an empty result.
  • It is the only one of the eight that needs a browser, which is why the pipeline has a headless renderer at all. It stays off by default; run the scraper with --allow-js after installing the optional extra to pick this one up.

What happens next, and who does it

  1. Open each source link and check the quoted evidence still matches the page. The parse is a convenience; the quote is the source.
  2. Resolve the UNKNOWN fields that matter for your situation — usually degree level, which year a deadline belongs to, and whether an award is per team.
  3. Fill in founder reviews from people who actually competed. Nothing else can produce that field.
  4. Set each row's review_status to ACCEPTED or REJECTED in data/opportunities.rutgers.candidates.json. Re-running the scraper preserves your decision and your reviews.
  5. Move accepted rows into data/opportunities.candidates.json and run scripts/verify_seed.py. That is the only path into the live catalog, and it is a person's job.
